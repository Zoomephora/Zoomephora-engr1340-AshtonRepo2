1. Align the numbers vertically: Line up the numbers by their place values (ones, tens, hundreds) on top of each other, making sure the rightmost digits (the ones column) align.
2. Add the ones column: Add the digits in the far-right column first. Write the sum directly below the line in the ones place.
3. Move left to the tens column: Add the digits in the next column to the left. Write the sum below the line.
4. Continue for all columns: Repeat this process moving from right to left for the hundreds, thousands, and remaining place values.
